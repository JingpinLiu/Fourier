Notebooks
=========

Intro_Fourier_Transformation.ipynb
    A self-contained introduction to the Discrete Fourier Transform (frequency,
    amplitude, phase) using simple toy signals. Start here if you are unfamiliar
    with Fourier analysis.

Fourier_Analysis_Demo.ipynb
    The full analysis pipeline described in the manuscript (docs/assets/Manuscript v0.3.pdf),
    reproducing every figure (1-10) on one example zebrafish (Fish 6): from the periodic
    stimulus signal, through per-neuron Fourier decomposition and amplitude/phase
    selection, to whole-brain spatial/phase maps and validation against regression
    analysis.

See the top-level README.md for setup instructions.
